옷가게에서 교환과 환불 요청하기

2026-10-20 · 읽는 시간 약 2분

사이즈가 안 맞거나 문제가 있을 때 영어로 교환·환불을 요청하는 표현이에요.

먼저 이유를 설명해요

왜 교환이나 환불을 원하는지 짧게 설명하면 직원이 처리하기 쉬워요. 영수증이 있다면 함께 보여 주세요.

  • This does not fit me.이게 저한테 안 맞아요.
  • It is too small. Do you have a bigger size?너무 작아요. 더 큰 사이즈 있나요?

환불을 요청할 때

환불 가능 기간이 있는지 확인하는 게 좋아요. 가게마다 기준이 다르니 물어보면 확실해요.

  • Can I return this?이거 반품할 수 있나요?
  • What is your return policy?반품 규정이 어떻게 되나요?

불량이 있을 때

제품에 문제가 있다면 구체적으로 어디가 문제인지 알려 주세요. 사진이 있으면 보여 주는 것도 도움이 돼요.

  • There is a hole in this shirt.이 셔츠에 구멍이 났어요.
  • It stopped working after one day.하루 만에 작동이 멈췄어요.

결과를 확인해요

처리가 끝나면 환불이 언제 들어오는지 물어보세요. 카드로 결제했다면 며칠 걸릴 수 있어요.

  • When will I get the refund?환불은 언제 받을 수 있나요?

1:1 화상 수업으로 직접 말하며 연습해 보세요.
