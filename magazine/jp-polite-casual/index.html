일본어 존댓말과 반말, 문장 끝만 바꿔 보세요

2026-10-20 · 읽는 시간 약 2분 · Photo: Unsplash

です·ます체를 반말로 바꾸는 규칙과, 어떤 상대에게 어떤 말투를 쓰는지 정리했어요.

말투는 상대에 따라 달라져요

일본어는 처음 만난 사람이나 윗사람에게는 です·ます체를 쓰고, 친한 사이에서는 반말을 써요. 반말을 처음 쓰는 상대에게 쓰면 실례가 될 수 있으니 상대가 먼저 쓸 때까지 존댓말을 쓰는 게 안전해요.

ます를 반말로 바꾸는 법

동사의 ます형을 기본형(사전형)으로 바꾸면 반말이 돼요. 부정형은 ません이 ない로 바뀌어요.

  • 食べます → 食べる먹어요 → 먹어
  • 行きます → 行く가요 → 가
  • 行きません → 行かない안 가요 → 안 가

です를 반말로 바꾸는 법

명사나 な형용사에 붙는 です는 だ로 바뀌지만, 질문에서는 だ를 쓰지 않고 말끝만 올려 물어요. い형용사 뒤의 です는 단순히 떼면 반말이 돼요.

  • 学生です → 学生だ학생이에요 → 학생이야
  • おいしいです → おいしい맛있어요 → 맛있어
  • 行きますか → 行く？가요? → 가?

일상에서 쓰는 짧은 말

친구와의 대화에서는 아래처럼 짧게 줄여 말하는 경우가 많아요. 처음 만난 사람이나 직장 동료에게는 쓰지 않는 편이 좋아요.

  • ありがとう고마워
  • ごめん미안
  • いいよ좋아
