일본어 과거형, た형 만드는 법

2026-10-20 · 읽는 시간 약 2분

동사를 과거형으로 바꾸는 방법을 그룹별로 정리했어요.

2그룹은 간단해요

食べる처럼 る로 끝나는 2그룹 동사는 る를 빼고 た를 붙이면 돼요.

  • 食べる → 食べた(taberu → tabeta)먹다 → 먹었다
  • 見る → 見た(miru → mita)보다 → 봤다

1그룹은 어미에 따라

1그룹은 어미에 따라 변화가 나뉘어요. く는 いた, ぐ는 いだ, む・ぶ・ぬ는 んだ로 바뀌어요.

  • 書く → 書いた(kaku → kaita)쓰다 → 썼다
  • 飲む → 飲んだ(nomu → nonda)마시다 → 마셨다
  • 話す → 話した(hanasu → hanashita)말하다 → 말했다

불규칙 동사

来る와 する는 불규칙이라 따로 외워야 해요. 자주 쓰니까 금방 익숙해져요.

  • 来る → 来た(kuru → kita)오다 → 왔다
  • する → した(suru → shita)하다 → 했다

정중한 과거

정중하게 말할 때는 ました를 써요. 상대에 따라 두 가지를 번갈아 쓰세요.

  • 昨日、映画を見ました。(kinō, eiga o mimashita)어제 영화를 봤어요.
