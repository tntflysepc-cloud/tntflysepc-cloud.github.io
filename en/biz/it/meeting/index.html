IT 회의 영어
실무에서 바로 꺼내는 문장

IT 회의 영어 수업은 IT 상황에 맞춘 말하기 위주예요. 포스트모템 회의에서 재발 방지책을 설명할 때 쓸 말부터 차근차근 다져요.

무료 상담 신청수업 방식 보기

이런 순간에 써요

상대 제안에 반대하지만 관계는 지키고 싶을 때 상대가 한 말을 다시 묻기도 애매하죠. 직장 내 괴롭힘 신고를 접수하고 절차를 안내할 때 필요한 말은 짧은 버전과 정중한 버전을 둘 다 연습해요. 신규 라인 시운전 결과를 공유할 때 쓰는 말은 수업 후반에 복습 겸 다시 해 봐요. cache, router, Linux처럼 한국식으로 읽던 단어가 회의에서 안 들릴 때가 있어서 실제 발음으로 다시 맞춰요.

이런 분께 맞아요

  • 해외 오픈소스 프로젝트에 이슈를 올리고 토론해 보고 싶은 분
  • 회의록을 영어로 정리해 올려야 하는 막내 사원분
  • 보상 체계를 설명하다 용어에서 막히는 분
  • 가동률과 생산성 지표를 영어로 보고하는 분

IT 회의 영어 수업에서 연습하는 문장

We rolled back the deploy, and error rates are back to baseline.

배포를 롤백했고 에러율은 평소 수준으로 돌아왔어요.

So to wrap up, Jenny will send the revised budget by Friday.

정리하면 제니가 금요일까지 수정 예산안을 보내기로 했어요.

Your total compensation includes base salary, an annual bonus, and benefits.

총 보상에는 기본급, 연간 성과급, 복리후생이 포함돼요.

When do you expect it to be back up?

언제쯤 다시 돌아갈 것 같아요?

Could we split this PR? It's hard to review as is.

이 PR 나눠 볼 수 있을까요? 지금 상태로는 리뷰하기 어려워요.

다루는 주제

배포 일정논점 되돌리기성과 평가안전 수칙기술 부채이해 확인 질문인력 충원시운전

선생님이 짚어 주는 것

영어로 말할 때 걸리는 부분은 사람마다 달라서, 아래 내용은 수업 중에 그때그때 짚어요.

1

fifteen과 fifty처럼 강세로 갈리는 숫자는 회의에서 실수가 잦아서 따로 듣기 연습을 해요.

2

base salary, bonus, benefits, total compensation처럼 보상 용어는 범위가 달라서 하나씩 구분해 설명하는 연습을 해요.

3

OEE, downtime, throughput 같은 생산 지표는 약어와 풀네임을 둘 다 알아들을 수 있게 연습해요.

IT 회의 영어 수업 흐름

수준 확인

짧게 대화하면서 지금 말하기 수준을 확인해요. IT 쪽에서 영어를 써 본 적이 있다면 같이 알려 주세요.

내 문장 만들기

논점 되돌리기 관련해서 내가 실제로 할 말을 직접 만들어 보고, 선생님이 더 자연스러운 표현으로 다듬어요.

다시 말하기

지난 시간에 막혔던 배포 일정 문장부터 다시 시작해요. 입에 붙을 때까지 반복해요.

수업 전 질문

상담은 어떻게 신청해요?

홈페이지 신청 양식에 이름, 연락처, 관심 언어를 남겨 주시면 확인 후 연락드려요.

IT 말고 다른 주제도 같이 할 수 있나요?

네. 수업 중간에 필요한 주제가 생기면 바꿔도 돼요. 논점 되돌리기 같은 주제와 섞어서 하는 분도 많아요.
