IT 비즈니스 영어, 이런 장면을 연습해요

거래처에 잔액 확인서를 요청할 때 필요한 건 긴 문법 설명보다 바로 꺼낼 한두 문장이에요. 로펌 청구 시간이 과하다고 이의를 제기할 때 생기는 일도 같은 방식으로 연습해요. 여유가 생기면 스프린트 회의에서 일정이 밀린 이유를 설명할 때 필요한 말도 이어서 다뤄요. 스탠드업은 어제 한 일, 오늘 할 일, 막힌 점을 한 문장씩 말하는 틀로 짧게 끊는 연습을 해요.

이런 분께 맞아요

  • 미국 본사와 매일 아침 스탠드업을 하는 백엔드 개발자분
  • IFRS 기준 용어를 영어로 설명해야 하는 회계 담당자분
  • 현업 부서의 영문 계약 질문에 답해야 하는 법무 담당자분
  • 글로벌 고객사 장애 콜에 들어가는 SRE분

실제로 쓰는 문장 예시

We're seeing elevated error rates in the EU region. Investigating now.

EU 리전에서 에러율이 올라가서 지금 조사하고 있어요.

Our intercompany balances don't match by about twelve thousand dollars.

법인 간 잔액이 1만 2천 달러쯤 안 맞아요.

In plain terms, this clause means we pay if they get sued.

쉽게 말하면 이 조항은 상대가 소송당하면 저희가 물어 준다는 뜻이에요.

Nit: this could be a constant. Not a blocker, though.

사소한 건데, 이건 상수로 빼도 될 것 같아요. 머지를 막을 정도는 아니에요.

I'm blocked on the API spec, so I'll pick up the logging ticket in the meantime.

API 명세 때문에 막혀서, 그동안 로깅 티켓을 먼저 할게요.

IT 비즈니스 영어 수업 흐름

수준 확인

짧게 대화하면서 지금 말하기 수준을 확인해요. IT 쪽에서 영어를 써 본 적이 있다면 같이 알려 주세요.

질문 받기

선생님이 분쟁 서면에 대해 질문하고 바로 대답해요. 대답이 짧으면 한 문장씩 늘려 가요.

다음 장면으로

한 장면이 편해지면 다음은 로펌 청구 시간이 과하다고 이의를 제기할 때 쓸 말로 넘어가요.

상담 전에 많이 묻는 것

전화 수업과 화상 수업은 뭐가 달라요?

화상은 얼굴을 보며 하니까 표정과 입 모양까지 볼 수 있어요. 전화는 장소 제약이 적은 편이에요.

IT 비즈니스 영어 수업은 화상으로만 하나요?

기본은 화상이고, 이동 중이거나 사정이 있는 날은 전화로도 해요. 상담 때 편한 방식을 말씀해 주세요.
