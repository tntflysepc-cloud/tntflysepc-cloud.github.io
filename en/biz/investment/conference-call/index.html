다른 일정 때문에 먼저 나가야 할 때 어떤 말로 시작할지부터 막히는 경우가 많아요. API 응답 형식이 문서와 달라 확인할 때 상대가 할 만한 질문도 미리 들어 보고 대답을 준비해요. 수업이 몇 번 쌓이면 기획안의 배경과 목적을 첫 장에서 설명할 때 할 말까지 범위를 넓혀요. IR 미팅에서는 guidance, headwind, tailwind 같은 시장 표현이 자주 나와요. 실적 설명 문장에 넣어 연습해요.

  • 블룸버그 채팅으로 해외 트레이더와 주문을 주고받는 채권 딜러분

  • 해외 법인과 연간 사업계획을 맞춰야 하는 기획팀 사원분

3

1:1 영어회화 수업 순서

상담

상담 때 영어를 언제 쓰는지 알려 주세요. 텀시트의 우선매수권 조항을 다시 협상할 때 필요한 말이라면 그 장면이 첫 수업 주제가 돼요.

질문 받기

선생님이 배포 일정에 대해 질문하고 바로 대답해요. 대답이 짧으면 한 문장씩 늘려 가요.

표현 넓히기

배포 일정처럼 이미 익힌 주제에 새 표현을 하나씩 더해요. 같은 말을 다르게 하는 연습도 해요.

자주 묻는 질문

수업 중에 한국어로 물어봐도 되나요?

어려운 표현은 확인하고 넘어가요. 수업 대부분은 영어로 대화하는 데 써요.

수업 내용을 제 상황에 맞출 수 있나요?

그럼요. 시간대 조율, 배포 일정처럼 실제로 쓸 주제를 알려 주시면 그 순서대로 다뤄요.
