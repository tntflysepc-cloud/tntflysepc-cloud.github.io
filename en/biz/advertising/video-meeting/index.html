경쟁 PT에서 크리에이티브 콘셉트를 3분 안에 소개할 때 바로 꺼낼 영어를 1:1로 미리 말해 봐요. 수업은 화상이 기본이고 전화로도 할 수 있어요.

막히기 쉬운 순간들

지연 때문에 상대와 말이 계속 겹칠 때 어떤 말로 시작할지부터 막히는 경우가 많아요. 실무 선에서 결정할 수 없는 걸 상대가 물을 때 필요한 말은 짧은 버전과 정중한 버전을 둘 다 연습해요. 여유가 생기면 API 응답 형식이 문서와 달라 확인할 때 필요한 말도 이어서 다뤄요. 광고주 피드백에는 I'm not sure it lands 같은 돌려 말하기가 많아요. 진짜 요구가 뭔지 되묻는 표현을 같이 연습해요.

광고 화상회의 영어, 이런 분께 추천해요

  • 해외 본사 크리에이티브 가이드를 로컬라이징하는 카피라이터분
  • 녹화되는 화상회의에서 말실수가 남을까 걱정하는 분
  • 팀 대표로 다른 부서와 협업 회의에 나가는 분
  • 기술 면접은 붙었는데 팀 스탠드업에서 말이 막히는 분

If we commit to the full quarter, could you throw in some bonus inventory?

분기 전체로 집행하면 보너스 지면을 좀 얹어 주실 수 있을까요?

Is everyone okay with me recording this?

이 회의 녹화해도 괜찮을까요?

I'll be running today's meeting on behalf of my manager.

The response has a nested object that isn't in the spec.

응답에 명세에 없는 중첩 객체가 있어요.

The review board flagged the word 'cure', so we'll need to change that line.

심의에서 '치료'라는 단어가 걸려서 그 문장은 바꿔야 해요.

목표 정하기

언제, 누구와 영어를 쓰는지 먼저 이야기해요. 키 비주얼처럼 당장 필요한 주제부터 순서를 정해요.

역할극

선생님이 상대역을 맡고, API 응답 형식이 문서와 달라 확인할 때 나올 대화를 그대로 재현해요. 같은 장면을 조건을 바꿔 두세 번 해요.

복습

수업에서 고친 문장을 정리해 두고, 다음 수업 처음에 다시 말해 봐요.
