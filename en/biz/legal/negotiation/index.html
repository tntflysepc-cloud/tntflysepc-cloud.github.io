막히기 쉬운 순간들

상대가 경쟁사 견적을 근거로 압박할 때 쓰는 표현은 몇 개만 입에 붙어도 마음이 놓여요. 실무 선에서 결정할 수 없는 걸 상대가 물을 때 쓸 문장은 녹음하듯 여러 번 말해 보고 다듬어요. 한 장면이 익숙해지면 API 응답 형식이 문서와 달라 확인할 때 쓸 말처럼 조금 까다로운 쪽으로 넘어가요. 협상 콜에서는 We could live with that if처럼 조건을 걸고 양보하는 표현을 연습해요.

이런 분들이 많이 찾아요

  • 해외 거래처와 공급계약서를 검토하는 사내 변호사분
  • 최종 결정권이 없는데 협상 테이블에 앉게 된 분
  • 해외 출장에 처음 혼자 가게 된 대리분
  • 장애 대응 중 해외 팀과 실시간으로 소통해야 하는 분

법무 협상 영어 수업에서 연습하는 문장

We can't accept uncapped liability, but we're open to a higher cap.

책임 한도를 없애는 건 어렵지만, 한도를 올리는 건 검토해 볼게요.

I don't think we can make this work this time.

이번에는 성사가 어려울 것 같아요.

This reads a bit abrupt. Maybe add a line thanking them first?

이건 좀 딱딱하게 읽혀요. 앞에 감사 한 줄 넣어 볼까요?

I went with a queue here because the API rate-limits us.

API 호출 제한이 있어서 여기는 큐로 처리했어요.

We've narrowed the indemnity to third-party claims only.

면책 범위를 제3자 청구로만 좁혔어요.

1:1 영어회화 수업 순서

수준 확인

짧게 대화하면서 지금 말하기 수준을 확인해요. 법무 쪽에서 영어를 써 본 적이 있다면 같이 알려 주세요.

실전 연습

준비한 문장을 읽지 않고 말해 보는 게 목표예요. 첫 제안 이야기가 나오면 선생님이 질문을 이어 가요.

다시 말하기

지난 시간에 막혔던 손해배상 문장부터 다시 시작해요. 입에 붙을 때까지 반복해요.

법무 협상 영어 궁금한 점

법무 말고 다른 주제도 같이 할 수 있나요?

할 수 있어요. 법무 장면을 연습하다가 일상 대화로 넘어가는 경우도 많아요.

수업 내용을 제 상황에 맞출 수 있나요?

그럼요. 첫 제안, 단독 출장처럼 실제로 쓸 주제를 알려 주시면 그 순서대로 다뤄요.
