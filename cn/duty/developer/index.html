개발자 상황에서 자주 막히는 순간

말이 겹쳐서 먼저 하시라고 양보할 때 짧게라도 먼저 말을 꺼내면 대화가 훨씬 편해져요. 양쪽 다 물러서지 않아 중간값을 제안할 때 대화가 엇나가는 경우까지 넣어서 연습하면 실제로 덜 당황해요. API 응답 형식이 문서와 달라 확인할 때 쓰는 말은 수업 후반에 복습 겸 다시 해 봐요. 숫자, 버전, 포트 번호를 읽을 때 1을 yāo로 읽는 습관이 있어서 듣기에서 헷갈리지 않게 익혀 둬요.

  • 합의한 내용을 그 자리에서 문장으로 확인하고 싶은 분
  • 장애 대응 중 해외 팀과 실시간으로 소통해야 하는 분
