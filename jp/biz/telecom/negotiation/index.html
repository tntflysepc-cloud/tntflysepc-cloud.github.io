통신 협상 일본어는 해저 케이블 단선으로 우회 경로를 논의할 때 쓸 말을 선생님과 직접 주고받으며 익히는 1:1 수업이에요.

통신 상황에서 자주 막히는 순간

협상이 막혀 잠깐 쉬었다 하자고 제안할 때 쓰는 일본어는 교재 예문과 꽤 달라요. 실무 선에서 결정할 수 없는 걸 상대가 물을 때 생기는 일도 같은 방식으로 연습해요. 그 밖에 API 응답 형식이 문서와 달라 확인할 때 필요한 말도 상담 때 알려 주시면 수업에 넣어요. 일본 통신사 장애 보고는 「障害発生」「影響範囲」「復旧見込み」 순서가 정해져 있어요. 이 틀대로 말하는 연습을 해요.

통신 협상 일본어 수업을 찾는 분들

  • 외국인 고객 개통과 요금제 상담을 맡은 대리점 직원분
  • 해외 거래처와 단가 협상을 처음 맡게 된 구매 담당자분
  • 메일은 되는데 즉석 통화에서 밀리는 분
  • 페어 프로그래밍에서 생각을 소리 내어 말하기 어려운 분

첫 대화

상황 바꿔 보기

API 응답 형식이 문서와 달라 확인할 때 오갈 대화를 하고 나면, 상대 반응을 바꿔서 한 번 더 해요.

짧게 점검

몇 번 수업한 뒤 처음 상담 때 말한 통신 장면을 다시 해 보고, 달라진 점을 같이 확인해요.

자주 묻는 질문

상담은 어떻게 신청해요?

홈페이지 신청 양식에 이름, 연락처, 관심 언어를 남겨 주시면 확인 후 연락드려요.
